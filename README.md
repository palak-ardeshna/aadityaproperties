# aadityaproperties.in

Static Jekyll site, built and hosted by GitHub Pages (no local build needed).

- Pages: `*.md` / `*.html` at the root. Articles: `_posts/YYYY-MM-DD-slug.md` (URL = `/slug/`).
- Real contact details go in `_config.yml` (`contact_email`, `contact_phone`, `operator_name`, `operator_city`). Empty values are not shown.
- Custom domain: add a `CNAME` file containing `aadityaproperties.in`, set `url: https://aadityaproperties.in` and `baseurl: ""` in `_config.yml`, then point DNS to GitHub Pages.
- Editorial workflow and checklists: see the documentation package one folder up.
